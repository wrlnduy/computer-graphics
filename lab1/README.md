# Лабораторная работа 1 — чётный вариант

Цветовые модели **CMYK — RGB — HSV**. HTML, CSS и JavaScript, без библиотек и сетевых запросов.

## Запуск

Откройте `index.html` в современном браузере. Сервер и установка пакетов не требуются.
Все файлы приложения должны оставаться в одной папке.

Дополнительно можно запустить локальный сервер из этой папки:

```sh
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Управление

- В каждой модели: числовой ввод, ползунки и двумерная палитра.
- Палитра CMYK меняет C и M при текущих Y и K.
- Палитра RGB меняет R и G при текущем B.
- Палитра HSV меняет S и V при текущем H.
- Кликните по палитре или перетаскивайте указатель. После фокуса можно использовать стрелки; Shift увеличивает шаг с 1 до 5.
- Общие средства: HEX `#RRGGBB`, системная палитра, девять готовых цветов и сброс.
- Невалидное числовое или HEX-значение показывает ошибку; текущий цвет сохраняется.
- При вводе любой компоненты остальные модели пересчитываются автоматически.

## Файлы

- `index.html` — структура страницы.
- `style.css` — оформление и адаптивная сетка.
- `color.js` — преобразования и единая точка пересчёта `convert`.
- `app.js` — построение интерфейса и обработка событий.
- `test.js` — автоматическая проверка математики, запуск `node test.js`.

## Численные особенности

RGB: 0–255; CMYK: 0–100%; HSV: H 0–360°, S и V 0–100%.
Поля поддерживают шаг 0.01. Во внутреннем состоянии сохраняются неокруглённые числа;
в полях показываются до двух знаков после запятой. HEX и экранная заливка округляются до 8 бит на канал.

Исходная модель сохраняется при пересчёте: обратное преобразование
RGB в CMYK неоднозначно. При пересчёте из RGB выбирается каноническое
значение K = 1 − max(R,G,B)/255. Для чёрного получается CMYK (0,0,0,100).
Из ахроматического RGB принимается H = 0; заданный вручную HSV сохраняет введённый H,
даже если S или V равны нулю. H = 360° даёт тот же цвет, что и H = 0°.

CMYK — учебная математическая модель без ICC-профилей, точного соответствия печати не обещает.
Все вычисления выполняются локально. Приложение не сохраняет данные после перезагрузки.
