# Лабораторная работа 2 — вариант 10

Глобальная пороговая обработка двумя методами и нелинейные фильтры на порядковых статистиках.

## Запуск

Откройте `index.html` в современном браузере. Установка пакетов и сервер не требуются.
Храните HTML, CSS и JavaScript в одной папке. Все вычисления выполняются локально.

Дополнительно можно запустить сервер из папки `lab2`:

```sh
python3 -m http.server 8000
```

И открыть http://localhost:8000.

## Работа с приложением

1. Выберите один из шести примеров или откройте свой файл через «Открыть изображение».
2. Выберите фильтр и размер окна 3×3, 5×5 или 7×7. Без фильтра оба метода используют исходное изображение.
3. Укажите, темнее ли объект фона. Белый цвет результата всегда обозначает выбранный объект.
4. Сравните результаты Оцу и итеративного среднего, их пороги и гистограмму.
5. Нажмите PNG у нужной панели для сохранения результата.

Параметры пересчитываются автоматически, изменения не накапливаются: каждый фильтр применяется к исходному полутоновому изображению.
Цветное изображение переводится в серый по формуле round(0.299R + 0.587G + 0.114B).
Прозрачность сначала накладывается на белый фон. У собственных изображений длинная сторона ограничивается 1024 пикселями с сохранением пропорций; принимаются файлы до 30 МБ.
Для пользовательского файла эталон неизвестен, поэтому MSE, ошибка сегментации и IoU не показываются.

## Методы

- **Оцу:** максимум межклассовой дисперсии для классов [0,T] и [T+1,255]. При равных максимумах выбирается первый порог.
- **Итеративное среднее:** начальный порог floor((min+max)/2); новый порог floor((mean_low+mean_high)/2). Остановка при неизменном пороге, защитный предел 256 итераций.
- **Медианный фильтр:** средний элемент отсортированного окна нечётного размера.
- **Минимальный фильтр:** наименьшее значение окна, подавление белых импульсов, расширение тёмных областей.
- **Максимальный фильтр:** наибольшее значение окна, подавление чёрных импульсов, расширение светлых областей.
- Границы продолжаются ближайшим пикселем (replicate). Для постоянного изображения оба порога равны его яркости.

## База изображений

В `samples/` находятся 6 исходных PNG, 6 чистых эталонов и 6 масок объекта.
Содержимое воспроизводится функцией `Samples.generate(id)` в `samples.js`.
Это контролируемые тестовые сцены, а не фотографии: известная маска позволяет количественно сравнить сегментацию.

| Пример | Что исследуется |
|---|---|
| `detail.png` | Объект с тёмными деталями; Оцу выделяет весь объект, итеративное среднее — только детали |
| `small.png` | Малый яркий объект; итеративное среднее отделяет его от более светлой области фона |
| `balanced.png` | Две разнесённые группы яркости; оба метода дают верную маску |
| `impulse.png` | Шум «соль и перец» с вероятностью 12%; медианная фильтрация |
| `salt.png` | Белые импульсы с вероятностью 12%; минимальный фильтр |
| `pepper.png` | Чёрные импульсы с вероятностью 12%; максимальный фильтр |

Суффикс `-clean` обозначает чистый эталон, `-truth` — маску (объект 255, фон 0).
Встроенные примеры используют такой же набор пикселей, что и PNG-файлы.

## Метрики и результаты

- Ошибка сегментации: доля пикселей, отличающихся от известной маски.
- IoU: пересечение выделенного и эталонного объекта, делённое на объединение; для двух пустых масок принимается 1.
- MSE: средний квадрат разности яркостей с чистым эталоном.

Измеренные значения приведены в `threshold-results.csv` и `filter-results.csv`.
На `detail` ошибка Оцу 0%, итеративного среднего 54.74%; на `small` — 51.80% и 0% соответственно.
Медиана 3×3 снижает MSE шума «соль и перец» с 2447.71 до 26.58.
Сравнение порогов выполняется без предварительного фильтра. Сравнение фильтров — для окна 3×3.

## Проверка алгоритмов

```sh
node test.js
```

Используется встроенный `node:assert/strict`, установка библиотек не требуется.
Оцу сопоставляется с независимым минимумом внутриклассовой дисперсии, ранговые фильтры — с прямой сортировкой каждого окна.
Проверяются в том числе углы, изображения меньше окна, постоянные значения, инверсия и сравнение с эталонами.
